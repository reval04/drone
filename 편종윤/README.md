# 군사용 전술 드론 통제 시스템 (Military Tactical Drone Control System)

## 프로젝트 개요
이 프로젝트는 2차원 평면 공간상에서 군사용 드론의 작전 경로를 무작위로 생성하고, 최단 거리 알고리즘을 통해 최적화하며, 배터리 소모량을 실시간으로 추적하는 C언어 기반 시뮬레이션 프로그램입니다. 
드론이 작전 수행 중 배터리 임계값에 도달하면 즉시 임무를 중단하고 스택(Stack) 자료구조를 활용해 통제실로 안전하게 역추적(회귀)하는 기능을 포함하고 있습니다.

## 주요 기능 및 파이프라인 (Step 01 ~ Step 04)

프로그램은 총 4개의 파이프라인(Step)으로 나뉘어 순차적으로 실행되며, 매 스텝마다 결과를 텍스트 파일로 저장하고 `notepad.exe`를 호출하여 사용자에게 결과를 시각적으로 제공합니다.

*   **Step 01: 작전 지역 웨이포인트 생성 (`01.c`)**
    *   0~500m 반경 내에서 난수를 이용해 5개의 타겟 좌표(x, y)를 생성합니다.
    *   작전에 투입되는 드론에게 1000~9999 사이의 고유 ID(`droneId`)를 무작위로 발급합니다.
    *   생성된 좌표는 `01.txt`에 저장됩니다.
*   **Step 02: 최단 거리 기반 경로 재구성 (`02.c`)**
    *   탐욕 알고리즘(Greedy)을 사용하여 통제실(`Z`: 0,0)을 기점으로 가장 가까운 거리의 웨이포인트 순으로 A, B, C, D, E 경로를 재구성합니다.
    *   재구성된 경로는 **연결 리스트(Linked List)** 에 순차적으로 저장되며 `02.txt`로 출력됩니다.
*   **Step 03: 배터리 소모 테이블 예측 (`03.c`)**
    *   재구성된 경로 간의 유클리디안 거리를 계산하여 예상 배터리 소모량을 산출합니다.
    *   구간 거리가 200m 이상일 경우 소모 계수 `K=1.7`을, 200m 미만일 경우 `K=1.5`를 적용하여 `배터리 소모 = 거리 * K` 공식으로 계산합니다.
    *   모든 구간의 소모량과 총 이동 거리(TOTAL)를 합산하여 `03.txt`에 누적 저장합니다.
*   **Step 04: 드론 기동 시뮬레이션 및 안전 회귀 (`04.c`)**
    *   드론이 경로를 전진할 때마다 현재 위치와 누적 소모량, 상태(`NORMAL`)를 **스택(Stack)** 에 `push` 합니다.
    *   안전 마진을 포함한 전체 필요 배터리의 약 1.3배를 최대 배터리로 설정하고, 그중 50%를 임계값(Threshold)으로 지정합니다.
    *   다음 경로로 이동 시 배터리가 임계값 미만으로 떨어질 것이 예측되면 즉시 기동을 중지(`FAILURE`)합니다.
    *   임무 실패 시 스택에서 이전 좌표들을 `pop` 하여 통제실(`Z`)까지 역추적(`RECOVERY`)하는 회귀 기동을 수행하며, 이 모든 과정의 로그를 `04.txt`에 기록합니다.

## 파일 구조 및 설명

*   **`01.c`**: 메인 함수(`main`)를 포함하며, 전체 파이프라인의 흐름 제어, 사용자 메뉴 UI, 그리고 난수 좌표 생성 로직을 담당합니다.
*   **`02.c`**: `01.txt`를 읽어 최단 경로를 탐색하고 연결 리스트 구조체에 할당하는 로직을 담당합니다.
*   **`03.c`**: 각 노드 구간별 거리 연산 및 배터리 소모량 예측 테이블(TOTAL 포함)을 작성합니다.
*   **`04.c`**: 드론의 실시간 배터리 차감 시뮬레이션과 스택을 이용한 회귀(역추적) 경로 문자열 포맷팅 기능을 수행합니다.
*   **`drone.h`**: `LinkedList`, `Stack`, 드론 상태 열거형(`DroneState`) 등 전역적으로 사용되는 자료구조 및 함수 원형이 정의된 헤더 파일입니다.
*   **`drone.c`**: `drone.h`에 선언된 연결 리스트(`createList`, `insertLast`, `freeList`)와 스택(`createStack`, `push`, `pop`, `isStackEmpty`)의 동적 할당 및 메모리 해제 구현부를 포함합니다.

## 🛠 핵심 자료구조

1.  **연결 리스트 (Linked List)**
    *   `LinkedList` 및 `ListNode` 구조체.
    *   역할: 통제실에서 결정된 최종 작전 경로(Z -> A -> B -> C -> D -> E)를 메모리상에 순차적으로 기록합니다.
2.  **스택 (Stack)**
    *   `Stack` 및 `StackNode`, `Position` 구조체.
    *   역할: 드론이 이동하며 안전하게 도달한 거점을 순서대로 쌓고(Push), 비상 상황 발생 시 LIFO(Last-In First-Out) 방식으로 최근 거점부터 꺼내어(Pop) 역순으로 복귀하는 데 사용됩니다.
